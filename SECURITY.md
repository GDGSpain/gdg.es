# Política de seguridad

Si encuentras una vulnerabilidad en gdg.es, **no abras un issue público**. Escribe a
reinaldo.aguilera@kairosds.com con una descripción, pasos para reproducirla y su impacto. Respuesta en un
plazo de 7 días.

Alcance: la web, el panel `/admin`, la API y el job de sincronización. Fuera de alcance:
gdg.community.dev (repórtalo a Google).
